# H - MotionData VM Disassembler

This repository contains a custom disassembler for a JavaScript-based virtual machine (VM) used in motion-related applications.

The VM implements 50 unique opcodes, is stack-based, and uses a string table for dynamic value resolution. The disassembler translates the VM’s bytecode into a readable instruction format.

---

## Purpose

This project is part of my learning journey in reverse engineering JavaScript VMs. It is the first time I have built a disassembler from scratch. All code and logic in this repository are written independently by me.

I am aware that a similar repository has been published recently. However, I want to make it clear that no code was copied. This is an original project created for educational purposes. I fully acknowledge that the result may not match the quality of more experienced developers, as I am still learning.

---

## Features

- Disassembler for a stack-based JavaScript VM
- Opcode mapping for all 50 known instructions
- String table decoding
- Clean, readable output for further inspection
