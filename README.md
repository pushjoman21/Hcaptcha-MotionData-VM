# Hcaptcha MotionData VM Disassembler

---

This project is an **H MotionData VM disassembler**.

I'm currently in the process of learning about JavaScript VMs, and while I acknowledge that the code might be messy and the opcode naming conventions are not ideal, I've decided to release this to potentially assist others who are also exploring JavaScript VMs.
